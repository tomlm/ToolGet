# ToolGet
ToolGet is a command line UI for installing dotnet tools.

![ToolGet](https://github.com/tomlm/ToolGet.Console/Assets/Screenshot.png)

## Features
🔍 **Package Search**
- Real-time NuGet package search using official NuGet API
- Search by package name, keywords, or authors

### Installing the Application

```bash
dotnet tool install -g ToolGet
```
