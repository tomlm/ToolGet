# ToolGet
ToolGet is a Cross-platform NuGet Package Search Tool for installing dotnet tools.

## Features
🔍 **Package Search**
- Real-time NuGet package search using official NuGet API
- Search by package name, keywords, or authors

### Installing the Application

```bash
dotnet tool install -g ToolGet
```
